# 阶段三：图书封面搜索、下载与核对规范

目标：拿到一张"就是这本书、且只有这本书、且没有销售类图片混入"的真实书封图，按书名命名落盘，并生成可用的头条竖版封面。

## 一、搜索渠道与优先级（按顺序尝试）

1. **共享图片目录**（`//你的主机/共享目录/书封/`）：用户常预先放置书名同名 jpg，先查这里。命中后必须先 ViewImage 核对版本（历史教训：目录里的《娱乐至死》是广西师大版，并非用户指定的中信版）。
2. **当当网（dangdang.com）**：商品主图信息完整，但主图常为 JS 动态渲染且带"满减/促销"水印，urllib 与 WebFetch 多拿不到干净主图。
3. **淘宝（taobao.com）**：补充与交叉验证渠道。
4. **豆瓣图书（book.douban.com）**：**纯书封最佳兜底来源**。两个渠道都搜一遍；当当/京东反爬或主图带促销时，直接用豆瓣。历史实测豆瓣封面 1000–1080px、无水印、纯书封，质量最稳定。

> 用户口中的"叮当网"按当当网处理（笔误）。

## 二、抓豆瓣纯书封（可靠兜底，已实测）

当当/京东主图 JS 渲染，直接抓 HTML 拿不到；豆瓣 subject 页的 `<meta property="og:image">` 稳定可用。步骤：

1. 从 ISBN 拿 subject ID：用 WebFetch 打开 `https://book.douban.com/isbn/{ISBN}/`，问出页面 URL 中的 subject ID（数字）与书名。
   - 例：《置身事内》ISBN 9787208171336 → subject 35546622；《法治的细节》ISBN 9787222204331 → subject 35635639；《娱乐至死》ISBN 9787508648286 → subject 26319730。
2. 用 `scripts/fetch_douban_cover.py --isbn <ISBN>` 或 `--sid <subject_ID>` 下载到素材根目录并命名为 `<书名>-书封原图.jpg`。脚本内部：请求 subject 页 → 正则取 og:image → 带 Referer 下载。
3. 或直接用 `--title` 让脚本按书名走 WebFetch 无法自动化的部分——脚本只负责已知的 subject ID / ISBN；未知 ID 时先按第 1 步用 WebFetch 查 ID。
4. 下载后必须过第四节核对三问。

```bash
python scripts/fetch_douban_cover.py --sid 35546622 --out "D:/book-notes/置身事内-书封原图.jpg"
```

## 三、用浏览器自动化搜索当当/淘宝

1. 用 mcp__browser__* 打开搜索页：
   - 当当：`http://search.dangdang.com/?key=<书名URL编码>`（注意当当用 GBK 编码，中文直接拼 URL 会乱码，优先用 `cua_type` 在搜索框输入中文，或按 GBK quote 构造 URL）。
   - 淘宝：`https://s.taobao.com/search?q=<书名URL编码>`。
2. 读可见 DOM，定位商品卡片中的封面主图与标题文字，优先"正版图书/官方旗舰店"。
3. 拿到图片 URL 后下载；反爬/需登录导致失败时转豆瓣兜底，或对书封区域截图保存（仍须过第四节核对）。

## 四、命名与落盘

- 目录：素材根目录（默认 `D:/book-notes/`，以用户指定为准）。
- 原图：`<书名>-书封原图.jpg`，书名用用户写法，去掉非法字符 `/\:*?"<>|`；中文标点（如《思考，快与慢》的逗号）可省略，全文保持一致。
- 成图：`<书名>-头条封面.png`。
- 不覆盖同名原图；替换前把旧文件改后缀备份。

## 五、核对三问（强制，逐条确认后才能进入下一步）

对每张候选图用 ViewImage 打开，逐条核对：

1. **书名/版本对不对**：图上书名（含副标题）、作者、出版社、版次是否与用户指定的同一本？近名书、多版次是高频坑：《传染》(Invisible Influence) ≠《疯传》(Contagious)；《娱乐至死》中信版（无头家庭插画）≠ 广西师大版（单人+电视）；《1984》新经典版（刘绍铭译）≠ 上海译文版（董乐山译）。遇到同名/近名/多版次必须看图确认，不能只看搜索标题。
2. **是不是纯书封**：有无"现货速发""正版保证""满减""包邮""销量10万+""2小时读完"等促销文字、店铺横幅、二维码、价格标签？历史教训：《置身事内》《法治的细节》共享图混入促销横幅，弃用改豆瓣；《认知觉醒》《象与骑象人》《非暴力沟通》是"书封+促销"电商拼图，须裁出纯书封区。
3. **有没有混入别的图**：是否夹着其他商品封面、赠品、周边？搜索结果是否把别的书当主图返回？发现混入即弃用。

任一问答不上来 → 停下，把候选图路径和疑问发给用户确认，禁止"先用了再说"，禁止用生成图或其他书图替代（用户明确偏好：真实书封优先，低清可增强修饰，但禁止生成图/其他图替代）。

## 六、生成头条封面

```bash
python scripts/enhance_cover.py --src "<书名>-书封原图.jpg" --out "<书名>-头条封面.png"
```

- 脚本逻辑：检测裁白边 → LANCZOS 放大到 1024×1536 竖版约 82% 高 → 提对比/饱和 + 锐化 → 同图高斯模糊压暗做背景 → 主体投影合成。全程只用这一张原图，不引入外部图片。
- 电商拼图（核对第 2 问发现促销文字）：须手动指定纯书封裁剪区：
  ```bash
  python scripts/enhance_cover.py --src "<原图>" --out "<成图>" --crop x0,y0,x1,y1
  ```
  历史验证过的裁剪区（200×200 图）：认知觉醒 `2,8,143,166`；象与骑象人 `14,10,170,166`；非暴力沟通 `0,0,140,168`；传染 `35,6,166,200`；乡土中国 `41,8,157,185`。新书按实际图重新目视确定，勿照抄。
- 生成后用 ViewImage 检查：书封主体完整无裁切、文字放大后可辨认、无残留促销文字。
- 低清图（200×200 缩略图）只增强不换图；增强后明显不可用（字全糊）时停下告知用户，由其决定是否提供高清图。
