# 阶段一：版本核实与纠错规范

目标：在动手做任何内容之前，把书的版本信息核实准确，并纠正用户识别信息中的错误。这么做的原因：同书名常有多个版次/译本，封面、目录、译者都不同；用户凭记忆给的识别信息可能出错，若照抄会写进笔记和发布任务，造成事实性错误。

## 一、必须核实的字段

- 书名（含副标题，如《置身事内：中国政府与经济发展》）
- 作者（外国作者含国籍与英文名规范写法）
- 译者（多译者全部列出，如"陈强 / 张永强 译"）
- 出版社 / 出版品牌（如"上海人民出版社 / 世纪文景""云南人民出版社 / 果麦文化"）
- 出版年月
- ISBN
- 目录结构（章节数 / 板块数）——用于笔记的"论证地图"与来源指针

## 二、核实方法

1. 联网搜索（WebSearch），优先出版社官网、豆瓣图书、图书馆 OPAC、孔夫子等可靠来源。
2. 交叉验证：至少两个来源一致才采信；不一致时以出版社官网/豆瓣条目为准。
3. 标注来源与检索日期，写入笔记开头，例："来源：豆瓣图书/出版社官网，2026-11-24 检索"。

## 三、对照用户识别信息逐项校验（关键）

把用户给的识别描述当作"待验证线索"，不是既定事实。逐项比对：

- **译者**：历史教训——《1984》用户给的信息写"董乐山译本（黑白老大哥侧脸）"，但核实发现北京十月文艺/新经典 2010 版（ISBN 9787530210291）实为**刘绍铭译**；董乐山译本是上海译文出版社版。最终按刘绍铭译本处理，并在笔记里做版本辨析说明。
- **版次/系列**：用户说"未名社科·大学经典版"《乡土中国》→ 核实为北大社 2012-10，ISBN 9787301174821（另有 2024 新版，按用户指定 2012 版处理）。
- **出版社**：用户说"中信出版社/三辉图书"《娱乐至死》→ 核实为中信出版集团 2015-05，章艳译，ISBN 9787508648286；共享目录里那张是广西师大版，版本不符必须换封面。

## 四、发现不符时的处理

1. 以核实结果为准，不照抄用户错误描述。
2. 在笔记里写一段"版本辨析"：用户描述是什么、核实结果是什么、依据是什么。
3. 交付时明确告知用户纠错结论（例：告诉用户 1984 新经典版译者是刘绍铭而非董乐山）。
4. 若用户的描述指向另一本真实存在的版本（如董乐山译本确实存在，只是不同出版社），说明两版差异，让用户确认按哪版；用户未回复时按封面实际版本处理并说明。

## 五、核实后的落盘

- 核实结果写入笔记开头的"原书基本信息"区，供后文引用，全文保持一致（作者名、译者名不得前后笔误，历史教训：把"埃利奥特"写成"埃利特"）。
- 版本信息属于 humanizer 保真红线中的"事实标注"，改写阶段不得改动。
