# 阶段四：Edge 浏览器发布标准作业流程（SOP）

适用：本地已安装 Microsoft Edge，且 Edge 中已登录头条号（沿用已有登录态）。基于 mcp__browser__* 浏览器自动化。本 SOP 已于 2026-11-19 至 11-23 多次实测通过。

## 前置条件与依赖

- Edge 已连接（browsers_list），取得 browser_id；已登录头条号（历史登录账号："你的头条号"）。未登录则提示用户手动登录，自动化不处理登录。
- Python 依赖：`pip install pillow pywin32`（剪贴板脚本 win32clipboard 需要）。
- Windows 上 PowerShell Add-Type 方案被安全策略拦截，不要用；剪贴板一律走 Python 脚本。

## 步骤

1. **接管页面**：`tabs_claim` 已有头条 tab，或 `tabs_new` + `tab_goto` 到 `https://mp.toutiao.com/`。
2. **幂等预检（先做）**：进入「作品管理」，按标题 + 日期核验目标文章是否已存在。已存在 → 判定成功并立即结束，严禁重复发布。
3. **清理半成品草稿**：打开「草稿箱」，若有同标题半成品草稿（从草稿箱打开的编辑页不会自动把正文首图识别为封面），先删除，再从「开始创作」新建。
4. **进入创作**：读 DOM 找到"开始创作"并点击。
5. **填标题（关键）**：
   - `dom_cua_click` 聚焦标题框 → `dom_cua_type` 输入主选标题。
   - **回显验证**：截图或读 DOM 确认标题已写入（如 14/30 字计数）、占位符消失。为空则重新 click + type 一次。
6. **粘贴封面图（已验证可行的剪贴板方案）**：
   - 写入剪贴板：
     ```bash
     python scripts/set_clipboard_image.py "<书名>-头条封面.png"
     ```
     （脚本把图片转 CF_DIB 位图写入系统剪贴板，已装 pywin32 即可。）
   - 在正文编辑器里**用坐标 `cua_click` 点击正文可编辑区**（`dom_cua_click` 点外层 div 不会聚焦，必须点正文文字实际位置），然后 `cua_keypress ["Control","v"]`。
   - 等 2–4 秒，截图确认图片出现在正文且显示"草稿已保存"，头条自动把正文第一张图设为封面。
   - 展开底部"发文设置"，确认封面区已显示该图（单图模式），必要时点"编辑"查看裁剪（默认 1024×797 横版裁剪框）。
   - 图片位置：放正文开头——先贴图，再填正文文字。拆书类文章正文开头带书封图可接受。
7. **填正文**：把 `<书名>-头条正文.txt` 全文用 `dom_cua_type` 写入（每次操作前重新 `dom_cua_get_visible_dom` 取最新 node_id，节点会失效）；写完读 DOM 确认内容存在（字数与预期相符）。
8. **发布**：
   - 底部固定栏有「预览 / 定时发布 / 预览并发布」；若被右下角调研弹窗遮挡，先定位 ✕ 关闭。
   - 坐标 `cua_click` 点"预览并发布"（坐标每次按当次截图重定位，勿复用历史坐标）。
   - 预览层点"确认发布"。
9. **发布后核验（不可省）**：发布按钮点击后通常**无成功弹窗/无跳转**，不能据"点了按钮"判定成功。回到「作品管理」刷新，确认该文章（标题 + 当天日期 + 状态"审核中"）确实出现，记录 pgc_id，才算成功。审核中暂无公开链接，只有后台预览链接，如实告知用户。
10. 列表里没出现 → 按第 3 步清理草稿后重试，最多 2 次；仍失败按 `check-mechanism.md` 写日志告警。

## 标题与标签

- 标题：`AI蒸馏《书名》高保真拆书笔记`（主选）；另备 3 个备选交付给用户。长度 20–28 字，标题框上限 30 字。
- 结尾带 5–6 个话题标签，覆盖赛道 + 动作（如 `#读书笔记 #拆书 #心理学 #成长 #思考`），按书的主题微调。
- 正文由 `scripts/md_to_toutiao.py` 从最终 md 转出：保留全部深度、去 markdown 符号、表格转标签行，标题写在 txt 第一行。

## 经验与坑

- 视口宽度会变（699/740/966/980 都出现过），所有坐标基于当次截图重定位。
- DOM 节点输入后常变，每次操作前重新 `dom_cua_get_visible_dom`。
- 标题用 dom_cua_click（节点）更稳；发布按钮用 cua_click（坐标）因为其在固定栏。
- 封面区位置不固定（正文下方或右侧栏），先整页截图定位。
- 粘贴必须坐标点击正文区；点"上传/替换封面"会唤起系统文件框（自动化硬限制），不要点。
- 发布按钮上绿色图标是鼠标指针，不是遮挡物。
- 定时发布会"发一半中断"（2026-11-20 实测）：留半成品草稿且无人发现。务必执行幂等预检 + 发布后核验 + 兜底任务，见 `check-mechanism.md`。
