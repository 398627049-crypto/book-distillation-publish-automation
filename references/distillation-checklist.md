# 阶段二：蒸馏流程与检查清单

## 一、蒸馏执行

1. 调用 `high-fidelity-book-distillation` skill，按其完整流程执行：
   - 默认产出 **High-Fidelity Learning Guide**（18 节 High-Fidelity Learning Guide 模板），不是短摘要、不是营销软文。
   - 3 层蒸馏：局部抽取 → 全书地图 → 内化输出；先重建论证地图，再写概念、主张、证据、批判、知识体系定位。
   - 按书型提取（证据驱动 / 观点驱动 / 方法驱动 / 行为驱动 / 叙事驱动 / 哲学社科 / 学习方法类），方法类必带 What-Why-How。
2. 输出文件：`<书名>-高保真拆书笔记.md`，落到素材根目录。

## 二、"之前要求"检查清单（每篇逐项打勾，不通过不进入下一阶段）

### A. 资料与真实性

- [ ] **只给书名时**：核实作者、出版年、出版社、目录结构（章节数），标注来源与检索日期（如"来源：孔夫子/图书馆/出版社官网，2026-11-24 检索"）。
- [ ] **明确注明**笔记"基于一般知识 + 公开目录结构"，因为用户未提供全书文本。
- [ ] **未编造**页码、章节标题、引文、研究、数据、Kindle 位置、作者原话。来源指针用章节名/小节名，不用假页码。
- [ ] 版权合规：没有大段复制原书文字，没有写成可替代原书的逐章改写。

### B. 书名与辨析

- [ ] 书名、作者、译者在全文一致，无前后笔误（历史教训：把"埃利奥特"写成"埃利特"）。
- [ ] **近名书 / 多版次**已辨析清楚（如《传染》Invisible Influence ≠《疯传》Contagious），并在笔记里说明依据。
- [ ] 文件名书名与正文书名一致；标题书名用中文标点（如《思考，快与慢》），文件名无逗号（如 `思考快与慢-...`），二者对应无误。

### C. 英文混入检查（每篇必做）

- [ ] 用 grep 扫描正文，清除中文语境里混入的英文词。历史每篇都修过 1–3 处，例如 controlled / largely / explains how / strong / flawed / rooted / how / priming。
- [ ] 保留例外：必要的专有名词（作者英文名、书名英文原名、术语缩写）、来源 URL 域名。
- [ ] 可用命令：
  ```bash
  grep -nP '[A-Za-z]{2,}' "<书名>-高保真拆书笔记.md"
  ```
  逐条看命中是否为允许的例外，不是就改成中文。

### D. 内容与结构

- [ ] 解释的是作者的论证（问题→主张→推理→证据→概念→实践→局限），不是话题列表。
- [ ] 概念先解释、建议后给出；主张与证据、故事、建议、推测分开标注。
- [ ] 有 Before/After 转变、批判性评估（哪里强、哪里过誉、哪里是轶事、哪里过时/受语境限制）、阅读路线、记忆与输出提示。
- [ ] 实用规则是条件式的（"适合…""当心…""前提是…"），不是绝对口号。
- [ ] **系列书籍**：更新"知识体系定位"表，做跨书关联（历史已形成群体心理系列 8 本 + 方法/成长系列 6 本）；新增书籍写清它在系列中的分工与上下游关系。
- [ ] **通俗读物 / 有争议观点**：如实标注严谨性局限与争议（如《认知觉醒》科学严谨性弱、《被讨厌的勇气》"心理创伤不存在"的争议），不吹捧。

## 三、自检后的产出

- 通过全部检查的 `<书名>-高保真拆书笔记.md`，交给阶段三 humanizer 改写。
- 若某条检查无法确认（例如资料来源找不到），在笔记里标注"待核实"并告知用户，不要编造填充。
