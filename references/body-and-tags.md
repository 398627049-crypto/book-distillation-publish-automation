# 阶段六：正文转换与话题标签规范

## 一、md 转正文

用 `scripts/md_to_toutiao.py` 把阶段五的润色版 md 转成头条正文 txt：

```bash
python scripts/md_to_toutiao.py \
  --src "D:/book-notes/<书名>-高保真拆书笔记-润色版.md" \
  --dst "D:/book-notes/<书名>-头条正文.txt" \
  --title "AI蒸馏《<书名>》高保真拆书笔记"
```

- 脚本行为：保留全部内容深度、去掉 markdown 符号、表格转标签行、标题写在 txt 第一行（正文从第三行起）。
- 标题主选格式固定为 `AI蒸馏《书名》高保真拆书笔记`；另备 3 个备选标题交付用户。标题 20–28 字，头条标题框上限 30 字。

## 二、补话题标签（必做，脚本不自动生成）

转换后的 txt **没有话题标签**，必须手工在正文末尾追加 5–6 个。覆盖维度：书名 + 作者 + 赛道 + 动作 + 主题微调。历史各篇示例：

| 书 | 话题标签 |
|---|---|
| 乡土中国 | `#乡土中国 #费孝通 #读书笔记 #社会学 #拆书 #传统文化` |
| 社会学的想象力 | `#社会学的想象力 #米尔斯 #读书笔记 #社会学 #拆书 #批判性思维` |
| 置身事内 | `#置身事内 #兰小欢 #读书笔记 #中国经济 #拆书 #经济学` |
| 法治的细节 | `#法治的细节 #罗翔 #读书笔记 #法律 #拆书 #法理思辨` |
| 娱乐至死 | `#娱乐至死 #波兹曼 #读书笔记 #传播学 #拆书 #媒介批评` |
| 1984 | `#1984 #奥威尔 #读书笔记 #反乌托邦 #拆书 #文学经典` |

追加方式（避免重复）：读取 txt，若末尾无 `#<书名>` 则 `rstrip() + 标签 + '\n'` 写回。

## 三、字数与交付核对

- 正文篇幅对照历史各篇 5100–7800 字（本次批量 5 篇为 5100–6100 字）。明显偏短（<3000）说明 md 转换异常，回查脚本。
- 核对三件事：① 第一行是主选标题；② 正文从第三行起（第二条为"原书：作者 著…"来源行）；③ 末尾标签完整。
- 输出绝对路径给用户，并给出主选+备选标题。
